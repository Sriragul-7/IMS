Because every figure is a real generated diagram embedded as a Word picture object, **no screenshots need to be replaced**. If you later wish to substitute a real screenshot for any diagram, select the picture in Word → **Picture Format** → **Change Picture** → **This Device…** The caption (a separate paragraph below the image) stays attached. Set picture width to ~13 cm and lock aspect ratio to keep consistency. Regenerate fields with `Ctrl+A` then `F9` to update TOC/List of Figures page numbers.
