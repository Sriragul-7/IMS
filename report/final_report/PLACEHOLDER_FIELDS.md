## HOW TO FILL

1. Open `Project_Report.docx` in Microsoft Word.
2. Press `Ctrl+F`, search for `[` to locate every placeholder bracket.
3. Replace each bracketed token with the actual value.
4. Remove highlighting after filling (optional).
5. Save and regenerate the TOC/fields: select the whole document (`Ctrl+A`) and press `F9`, or right-click each field → "Update Field".
